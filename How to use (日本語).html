TextToVoicevox ・ Windows版

入れてから、しゃべらせるまで

PDF・画像・テキストの文字を取り出して、ずんだもんなどの VOICEVOX の声で読み上げるアプリです。ぜんぶ自分のパソコンの中で動き、文字をネットに送りません。このページは、アプリの右上の 使い方 からも開けます。

VOICEVOX→Python→アプリ→ 読み込む→取り出す→声を選ぶ→音声にする

準備（最初の1回だけ）

この順番で入れます。VOICEVOX と Python は別のソフトなので、アプリには入っていません。

  1. 1

    VOICEVOX を入れる

    声を作っている本体です。VOICEVOX 公式サイトからダウンロードしてインストールします。

    • 入れれば、あとは何もしなくて大丈夫です。アプリを開くと、VOICEVOX の読み上げの部分も自動で立ち上がります（エディタ画面は開きません。アプリを閉じると一緒に終わります）。
    • エディタ画面も使いたいときは、アプリの VOICEVOX起動 ボタンから立ち上げられます。
    • 自動で立ち上げたくないときは、左下の 接続設定… の中の アプリと一緒に VOICEVOX を起動 を切ります。
    • GPU のあるパソコンで、VOICEVOX が GPU を使える版なら、GPU を使って起動します（音声を作るのが速くなります。測ったパソコンでは約4倍）。切るときは、同じ所の GPU があれば使う を外します。
  2. 2

    Python を入れる

    python.org から 3.9 以降のインストーラを落として実行します。

    ここが一番のつまずきどころ

    インストーラの最初の画面で「Add python.exe to PATH」に必ずチェックを入れてから進めてください。

  3. 3

    アプリを起動する

    展開したフォルダの 起動.pyw をダブルクリックします。

    • 初回だけ黒い窓でセットアップが進みます（ネット接続が必要・数分）。
    • 終わるとそのままアプリが開きます。2回目からはすぐ開きます。
    • 1回開くと、アプリの絵の「TextToVoicevox」ができて、起動.pyw は app フォルダの中にしまわれます。次からは「TextToVoicevox」を開きます。
    • 新しい版が出ると、上の帯に「新しい版があります」と出ます。押すと入れ替え方が出ます。
    • zip は必ず右クリック →「すべて展開」してから使います。

    別の入れ方：ターミナルに1行貼るだけ（Python も要らず、警告も出ず、デスクトップにアイコンができます）

    irm https://raw.githubusercontent.com/rakuyou211-blip/TextToVoicevox/main/install.ps1 | iex

画面の見かた

開いた画面は2列です。左の列に手順（① → ② → ③）、右に本文と再生バーが並びます。左の列を上から順に使っていきます。

TextToVoicevox ・ 状態のお知らせ ・ テーマ ・ 使い方 ・ 感想を送る
① 取り込むファイルをドロップ／スクリーンショット → ▶ テキスト抽出 実行。ページ範囲や文の整え方は「設定 ▷」
② 声選んだ声のキャラの顔（押すと声のサンプル）・キャラとスタイル・速さなど → ♪ 声を聴く／▶ 試聴
③ 保存音声形式・まとめ方（最初は全部を1つに）・字幕 → ♪ 音声を生成
接続● 接続OK／VOICEVOX起動・画面なしで起動／一緒に起動の切り替え
本文取り出した文字がここに出ます。手で直せます（60秒ごとに自動保存）。漢字の上に、VOICEVOX が実際に読む読み（ふりがな）が出ます
再生バー◁ 前の行・▶ 再生・次の行 ▷・■ 停止・« 最初から・速さ・間・あと◯分・◁ 広げる

ボタンの色：テーマの色で塗ったボタンが大事な操作（▶ テキスト抽出 実行・♪ 音声を生成・▶ 再生。ライト・ダークはオレンジ、ずんだは緑、くっきりは青）、面のあるボタンがよく使う操作、枠だけのボタンがときどき使う操作（.txt 保存・コピー・前の行／次の行など）です。面のない文字は道具で、歯車の印が付いたものは設定を開きます。赤い文字の 本文を全消去 は本文を消すボタンです。

使い方（毎回の流れ）

ファイルを入れて、文字を取り出して、声にする。基本はこの4つです。

  1. 1

    左の列 ① 取り込む

    読ませたいものを入れる

    PDF・画像（PNG/JPG など）・txt・docx・epub を画面にドラッグ＆ドロップします。

    • 画面に出ている文字を読ませたいときは スクリーンショット（Ctrl+R）で範囲を囲むだけ。囲んだらすぐ読み上げます。
  2. 2

    左の列 ① 取り込む → 右の本文

    文字を取り出す

    ファイルを入れると、自動で文字を取り出して、右の本文に出します。取り出し直すときは ▶ テキスト抽出 実行（Ctrl+Enter）。

    • PDF は 5-320 のようにページ範囲を決めて、表紙や目次を飛ばせます（① の 設定 ▷）。
    • PDF の本で、ページごとの上や下に出る本や章の名前（柱）とページ番号は読みません（章の見出し〔第一章 など〕は、最初の1回を残します）。外した行は 直した所 で見られます。
    • スキャンや写真の文字も読み取ります（縦書きは右の列から）。ゲームや写真の上の文字、小さな文字、英語まじりの文も読めます。
  3. 3

    右の本文 ／ 左の列 ② 声

    直して、声を選ぶ

    本文はそのまま書き直せます。漢字の上のふりがなは VOICEVOX が実際に読む読みなので、聴く前に読み間違いを見つけられます（色つきのふりがなを押すと、その語の読みを直せます）。② でキャラと声の種類を選び、▶ 試聴（Ctrl+P）で聞いて確かめます。

    • ふりがなは、VOICEVOX が動いているときに出ます。動いていないと、本文のすぐ上に「ふりがな（漢字の上の読み）は、VOICEVOX を起動すると出ます」と出ます。となりの 画面なしで起動 で、そのまま起動できます。窓の幅が狭いときは、ふりがなのチェックは本文の下にあります。
    • 「誤読候補だけ」にチェックを入れると、色つきのふりがな（誤読かもしれない読み）だけを出します。
    • 長い本では、本文の右上の 次の候補 ▷（F8。前へは Shift+F8）で、色つきのふりがなの所へ順に移れます。まだ読みを調べていない行は、VOICEVOX に聞きながら探します。
    • 本文の文字は、窓を広げると大きくなります（狭い窓では小さくしません）。好みの大きさは Ctrl+＋／－（Ctrl+ホイールでも）、元に戻すのは Ctrl+0。右クリックの「文字の大きさ」で、窓に合わせるかどうかも選べます。
    • 行の頭に @ずんだもん: と書くと、その行だけ声が変わります（掛け合いに）。
    • 行の頭に # を付けた行は読みません（メモ用）。
    • 読み間違いは、右クリック →「選択語を辞書登録」で直せます。
    • 日付・時刻・記号（25℃・10:30・2026/11/7・10〜20人 など）は、VOICEVOX が読み間違えないよう、アプリが読み上げる前に直します（本文の字は変わりません）。切るときは 読み方辞書... の窓のいちばん上の 数字・日付・記号の読み方を直す で。
  4. 4

    本文の下の再生バー ／ 左の列 ③ 保存

    聞く、または音声ファイルにする

    • ▶ 再生（本文のすぐ下）… カーソルのある行から最後まで読み上げ。Space で一時停止・再開。読んでいる行は本文欄の上から3分の1あたりに保つので、次の文も見えます。再生バーの右に、何行目かと「あと約◯分」が出ます。
    • ◁ 広げる（F11。再生バーの右端）… 左の列を畳んで、本文を窓いっぱいに広げます。文字も窓の幅に合わせて大きくなります。▷ 戻す か、何も鳴っていないときの Esc で戻ります。
    • ♪ 音声を生成（Ctrl+G）… ③ で選んだ形式（WAV など）のファイルに保存。最初は全部を1つのファイルにまとめます（③ の まとめ方 で変えられます。ファイルが300個を超えるときは、作る前に聞きます）。字幕(.srt)も保存 にチェックすると字幕も一緒に出ます。
    • 段落・章は長め（③ の「文の間」の右。最初からオン）… 段落が変わる所（空行のあと・行頭の字下げ）と章の見出し（第一章 など）の前は、文の間より長く空けます（0.4秒なら 1.0秒・2.0秒）。再生にも保存にも効きます。行頭の字下げ（全角スペース）でも段落を見分けるので、小説などは 空行を削除 のままでも段落の間が空きます。
    • 途中で止めるときは Esc。そこまでの分を保存することもできます。

保存できる形式

形式用途必要なもの
WAVいちばん確実。動画編集にもそのまま使えるなし
M4A / MP3スマホで聞く、容量を小さくしたいffmpeg
M4B(本)章つきオーディオブック（第◯章で自動で区切る）ffmpeg
.srt音声に合わせた字幕なし

うまくいかないとき

起動.pyw をダブルクリックしても何も起きない／メモ帳が開く

Python が入っていないか、PATH のチェックを忘れています。準備 2 をやり直してください。Python が入っているのにメモ帳が開くときは、右クリック →「プログラムから開く」→「Python」を選びます。

「WindowsによってPCが保護されました」と出る

小さな「詳細情報」を押して、「実行」を押します。作者がコード署名をしていないだけで、中身はすべて公開されています。

「VOICEVOX: つながっていません」と出る

VOICEVOX が動いていません。入っていれば、ふつうはアプリを開くと自動で立ち上がります。立ち上がらないときは、アプリの左下（接続）の VOICEVOX起動 か 画面なしで起動 を押します。毎回そうなるときは、左下の 接続設定… の中の アプリと一緒に VOICEVOX を起動 がオンか確かめてください。

ふりがなが出ない

ふりがなは、VOICEVOX につながっているときにだけ出ます（つながっていないときは、本文のすぐ上にそう出ます）。VOICEVOX を立ち上げるか、その一言のとなりか、アプリの左下（接続）の VOICEVOX起動 か 画面なしで起動 を押すと、つながったところで自動で出ます。窓の幅が狭いときは、ふりがなのチェックは本文の下にあります。

原因がわからない

デバッグ起動.pyw で起動すると、黒い画面にエラーの内容が出ます。フォルダの「起動エラー.log」「エラー.log」にも記録が残ります（zip で入れた人は、どれも app フォルダの中）。

作った音声を公開するときは、VOICEVOX と各キャラクターの利用規約に従い、「VOICEVOX:ずんだもん」のようなクレジットを付けてください。完了画面のボタンでコピーできます。
