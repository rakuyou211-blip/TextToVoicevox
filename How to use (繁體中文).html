TextToVoicevox ・ Windows 版

從安裝到開口朗讀

把 PDF、圖片、文字檔裡的文字取出來，用ずんだもん等 VOICEVOX 的聲音唸出來的軟體。全部在你自己的電腦裡執行，文字不會傳到網路上。這一頁也可以從本軟體右上角的 使い方（使用說明）打開。

軟體的畫面只有日文。下面的按鈕名稱照軟體裡的日文寫，並附上中文說明。

VOICEVOX→Python→本軟體→ 加入檔案→取出文字→選擇聲音→變成語音

準備（只有第一次）

請照這個順序安裝。VOICEVOX 和 Python 是另外的軟體，沒有包含在本軟體裡。

  1. 1

    安裝 VOICEVOX

    負責產生聲音的主程式。請從 VOICEVOX 官方網站 下載安裝。

    • 裝好之後就不需要再做什麼。開啟本軟體時，語音引擎會自動一起啟動（不會開編輯器視窗，關閉本軟體時也會一起結束）。
    • 也想用編輯器視窗時，可以用本軟體的 VOICEVOX起動（啟動 VOICEVOX）按鈕開啟。
    • 不想自動啟動時，可以關掉左下角 接続設定…（連線設定）裡的 アプリと一緒に VOICEVOX を起動（和本軟體一起啟動 VOICEVOX）。
    • 如果電腦有 GPU，且 VOICEVOX 是可使用 GPU 的版本，本軟體會用 GPU 啟動（產生聲音會快很多；在測試的電腦上約快 4 倍）。要關掉時，取消同一處的 GPU があれば使う（有 GPU 就使用）。
  2. 2

    安裝 Python

    從 python.org 下載 3.9 以上版本的安裝程式並執行。

    最容易卡住的地方

    在安裝程式的第一個畫面，一定要先勾選「Add python.exe to PATH」再繼續。

  3. 3

    啟動本軟體

    在解壓縮後的資料夾裡，按兩下 起動.pyw。

    • 只有第一次會出現黑色視窗進行設定（需要連網，約幾分鐘）。
    • 完成後會直接開啟本軟體，之後就能馬上開啟。
    • 開啟一次之後，會出現有本軟體圖示的「TextToVoicevox」捷徑，起動.pyw 會收進 app 資料夾。之後開這個捷徑就可以了。
    • 有新版本時，上方會出現「新しい版があります」，按下去會說明怎麼更新。
    • zip 檔請務必先按右鍵 →「全部解壓縮」再使用。

    另一種安裝方式：在終端機貼上一行就好（不需要 Python，不會出現警告，桌面會出現圖示）

    irm https://raw.githubusercontent.com/rakuyou211-blip/TextToVoicevox/main/install.ps1 | iex

使用方法（每次的流程）

加入檔案、取出文字、變成語音。基本上就是這四步。

  1. 1

    左欄 ① 取り込む

    加入要唸的東西

    把 PDF、圖片（PNG／JPG 等）、txt、docx、epub 拖放到視窗上。

    • 想唸畫面上的文字時，按 スクリーンショット（截圖，Ctrl+R）框住範圍就好，框完會馬上唸出來。
  2. 2

    左欄 ① 取り込む → 右邊的本文

    取出文字

    加入檔案後會自動取出文字，顯示在右邊的本文。想重新取出時，按 ▶ テキスト抽出 実行（Ctrl+Enter）。

    • PDF 可以用 5-320 這樣的頁數範圍，跳過封面和目錄（① 的 設定 ▷）。
    • PDF 的書每頁上方或下方的書名、章名（頁眉）和頁碼不會唸出來（章節標題〔第一章 等〕的第一次會保留）。去掉的行可以在 直した所（修正的地方）查看。
    • 掃描檔和照片上的文字也能辨識（直書會從右邊的行開始），遊戲畫面和照片上的文字、小字、日文夾雜英文的句子也讀得出來。
  3. 3

    右邊的本文／左欄 ② 声

    修改並選擇聲音

    本文可以直接修改。漢字上方的假名是 VOICEVOX 實際的唸法，聽之前就能發現唸錯的地方（點一下有顏色的假名，就能修正那個詞的讀音）。在 ② 選擇角色和聲音風格，再用 ▶ 試聴（Ctrl+P）試聽確認。

    • 假名讀音只有在 VOICEVOX 執行時才會顯示。沒有執行時，本文正上方會顯示 「ふりがな（漢字の上の読み）は、VOICEVOX を起動すると出ます」（啟動 VOICEVOX 後就會顯示讀音），按旁邊的 画面なしで起動 就能直接啟動。視窗較窄時，假名的勾選框在本文下方。
    • 勾選 「誤読候補だけ」，就只顯示有顏色的讀音（可能唸錯的地方）。
    • 長篇的書，可以用本文右上角的 次の候補 ▷（下一個候選，F8；回到上一個是 Shift+F8），依序跳到每個有顏色的讀音。還沒查過讀音的行，會一邊問 VOICEVOX 一邊找。
    • 把視窗拉寬，本文的文字就會變大（視窗窄的時候不會變小）。用 Ctrl+＋／－（或 Ctrl＋滑鼠滾輪）調整成喜歡的大小，Ctrl+0 恢復。按右鍵的 「文字の大きさ」（文字大小）可以選擇要不要配合視窗。
    • 在行首寫 @ずんだもん:，就只有那一行換成別的角色（適合對話）。
    • 行首加上 # 的行不會唸出來（可以當備註）。
    • 唸錯的詞，也可以選取後按右鍵，登錄到讀音字典來修正。
    • 日期、時間、符號（25℃、10:30、2026/11/7、10〜20人 等），本軟體會在朗讀前先改成 VOICEVOX 唸得對的寫法（本文不會改變）。要關掉時，請取消 読み方辞書...（讀音字典）視窗最上方的 数字・日付・記号の読み方を直す。
  4. 4

    本文下方的播放列／左欄 ③ 保存

    收聽，或存成音檔

    • ▶ 再生（本文正下方）… 從游標所在的行唸到最後。按 Space 暫停／繼續。正在唸的行會保持在本文欄上方約三分之一的位置，看得到下一句。播放列右邊會顯示第幾行和 あと約◯分（還剩大約幾分鐘）。
    • ◁ 広げる（放大本文，F11，在播放列右端）… 收起左欄，讓本文佔滿整個視窗，文字也會跟著變大。按 ▷ 戻す，或在沒有播放時按 Esc 就能恢復。
    • ♪ 音声を生成（Ctrl+G）… 存成在 ③ 選擇的格式（WAV 等）的檔案。預設把全部存成一個檔案（可在 ③ 的 まとめ方（分割方式）更改；檔案會超過 300 個時，產生前會先詢問）。勾選 字幕(.srt)も保存 就會同時輸出字幕。
    • 段落・章は長め（段落和章節之間停久一點；在 ③ 的 文の間 右邊，預設開啟）… 換段落的地方（空行之後、行首縮排）和章節標題（第一章 等）之前，會停得比句子之間久（句間 0.4 秒時，分別是 1.0 秒和 2.0 秒）。播放和存檔都適用。行首用全形空格縮排的段落，即使開著 空行を削除 也認得出來。
    • 想中途停止時按 Esc。也可以把已經做好的部分存下來。

遇到問題時

按兩下 起動.pyw 沒有反應／開啟了記事本

沒有安裝 Python，或是忘了勾選 PATH。請重做準備的第 2 步。已經安裝 Python 卻開啟記事本時，請按右鍵 →「開啟檔案」→ 選擇「Python」。

出現「Windows 已保護您的電腦」

按下小字的「其他資訊」，再按「仍要執行」。只是作者沒有做程式碼簽章，原始碼全部公開。

出現 「VOICEVOX: つながっていません」（沒有連上 VOICEVOX）

VOICEVOX 沒有在執行。裝好之後，通常開啟本軟體時就會自動啟動。如果沒有啟動，請按本軟體左下（接続）的 VOICEVOX起動 或 画面なしで起動。如果每次都這樣，請確認左下角 接続設定… 裡的 アプリと一緒に VOICEVOX を起動 有打開。

沒有顯示假名讀音

假名讀音只有在連上 VOICEVOX 時才會顯示（連線之前，本文正上方會這樣提示，旁邊還有 画面なしで起動 按鈕）。開啟 VOICEVOX，或按本軟體左下（接続）的 VOICEVOX起動 或 画面なしで起動，連上後就會自動顯示。視窗較窄時，假名的勾選框在本文下方。

不知道原因

用 デバッグ起動.pyw 啟動的話，黑色視窗會顯示錯誤內容。資料夾裡的 起動エラー.log、エラー.log 也會留下紀錄（用 zip 安裝的話，都在 app 資料夾裡）。

公開你做的音檔時，請遵守 VOICEVOX 和各角色的使用條款，並加上「VOICEVOX:ずんだもん」這樣的來源標示。完成畫面上的按鈕可以複製標示文字。
