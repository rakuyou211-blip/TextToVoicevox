# TextToVoicevox 🍂

🌐 **[English](README.en.md)** ｜ **[日本語](README.md)** ｜ **[繁體中文](README.zh-TW.md)** ｜ 简体中文（本页）

把 PDF、图片、电子书、青空文库里的日文，交给 VOICEVOX 的声音（ずんだもん等）读给你听的免费桌面软件。全部在你自己的电脑上完成，不会把文件上传到网络。

我是 rakuyou211，一个人做软件的业余开发者。一开始只是想让电脑把书和长长的 PDF 读给我听，就这样一直做到了现在。还有很多不够完善的地方，下面会如实写出来。

> **非官方工具**：本软件不是 VOICEVOX 官方的软件，而是个人制作的工具，与 VOICEVOX 的开发方及各角色的权利人没有关系。VOICEVOX 本体需要另外安装（本软件没有附带）。

> ⚠️ **先说清楚：软件的界面（按钮和菜单）目前只有日文。** 读出来的内容也是日文。比较适合已经看得懂一些日文的人，例如正在学日语、想听自然日语发音的人。

## 适合谁

- **正在学日语的人**：把日文文章（课本、小说、新闻截图）变成自然的日语语音。正文的汉字上方会直接显示 VOICEVOX 的读音（假名），可以用来确认汉字怎么读。
- **想用耳朵读日本文学的人**：直接读取 [青空文库](https://www.aozora.gr.jp/)（版权已过期的日本名著，免费公开）的文字，会自动去掉注音标记。
- **眼睛累、不想再盯着小字的人**：扫描的 PDF、拍下来的书页，都能变成声音。

## 能做什么

- **直接读屏幕上的文字**：点「📷 スクリーンショット」（截图），用鼠标框住屏幕上的文字（电子书、PDF、网页），马上读出来（Ctrl+R ／ ⌘R）。
- **支持多种文件**：PDF（含扫描件）、图片（PNG・JPG 等）、`.txt`、`.docx`、`.epub`。
- **PDF 的页眉和页码不读**：PDF 书每页上方或下方的书名、章名（页眉）和页码会去掉，不会每页都读一次（章节标题〔第一章 等〕的第一次会保留；去掉的行可以在「直した所」查看）。
- **离线 OCR**：图片和扫描件的文字都在电脑里识别，不会上传。Windows 使用 PP-OCRv6，**第一次设置时会自动安装，不需要点任何按钮**（下载约 122MB，安装后约占 100MB）。游戏画面和照片上的文字、小字、日文夹杂英文的句子也读得出来（我们测试的 258 张图片中，读对的字是 99.7%，Windows 自带的识别是 89%）。没装成时会改用 Windows 自带的 Windows.Media.Ocr，并在 ① 的「設定 ▷」里出现「読み取りを強くする」，可以从那里重新安装。Mac 使用 Apple Vision。竖排文字会从右边的列开始依次读。
- **用 VOICEVOX 的声音朗读**：在自己的电脑上生成语音，可以调节速度（速さ）、音高（高さ）等。
- **先改正容易读错的写法**：数字、日期、符号等 VOICEVOX 容易读错的写法，本软件会在朗读前先改成能读对的写法（不会改动正文。例如 `25℃`→25度、`10:30`→10時30分、`2026/11/7`→2026年11月7日、`10〜20人`→10から20人、`-5℃`→マイナス5度）。连续播放、试听、保存音频、假名读音和给 VOICEVOX 的导出（.txt・.vvproj）都适用。默认开启，可以在「読み方辞書...」窗口最上方的「数字・日付・記号の読み方を直す」关掉。
- **显示声音角色的脸**：在「② 声」选好的声音旁边，会显示该角色的官方插图（每种风格的表情不同）。点一下就能听声音样本。图片来自你电脑上的 VOICEVOX，本软件没有附带。
- **一行换一个角色**：在行首写 `@ずんだもん:` 之类的，就能换成别的声音，做对话朗读也很方便。
- **导出音频和字幕**：随时可以保存为 WAV；也能导出 MP3・M4A，以及带章节的有声书 M4B（格式选「M4B(本)」。Windows 需要另外安装 ffmpeg；Mac 只有 MP3 需要）。还能同时导出对齐的 `.srt` 字幕。默认把全部保存成一个文件（「③ 保存」的「まとめ方」是「全部を1つに」），也能改成每行一个文件等；文件会超过 300 个时，生成前会先询问。
- **跟着正在读的行**：连续播放时，正在读的行会保持在正文栏上方约三分之一的位置，所以看得到下一句，换行的长句结尾也不会被遮住（自己滚动之后，会等 6 秒再跟上）。播放栏右边会显示第几行和「あと約◯分」（还剩大约几分钟）。
- **把正文放大（阅读模式）**：点播放栏右端的「◁ 広げる」（F11），左栏会收起来，正文占满整个窗口，文字也会随窗口的宽度变大。点「▷ 戻す」，或在没有播放时按 Esc 就能恢复。
- **段落和章节之间停久一点**：换段落的地方（空行之后，或行首用全角空格缩进）停顿是句间的 2.5 倍，章节标题（第一章、プロローグ 等）之前是 5 倍（句间 0.4 秒时，分别是 1.0 秒和 2.0 秒）。播放、保存的音频、字幕和 M4B 的章节时间都适用。可以用「③ 保存」的「段落・章は長め」切换（默认开启）。行首用全角空格缩进的段落也能认出来，所以小说等即使开着「空行を削除」（删除空行，默认开启）也会在段落之间停顿。没有缩进的文字要在段落之间停顿时，请在「① 取り込む」的「設定 ▷」取消勾选「空行を削除」。
- **读音词典**：读错的词登记一次就会记住。
- **汉字上方显示读音（假名）**：正文的汉字上方会显示 VOICEVOX 实际的读法（默认开启），听之前就能发现读错的地方。和词典不同的读音会用颜色标出（可能读错），点一下就会打开读音词典，可以直接修正。只想看可能读错的地方时，请勾选「誤読候補だけ」。篇幅长的书也可以点「次の候補 ▷」（F8；回到上一个是 Shift+F8），依次跳到每个可能读错的地方。
- **正文文字大小随窗口变化**：把窗口拉宽，正文（和假名）的文字会跟着变大，直到一行大约 36 个字；窗口窄的时候不会变小。可以用 Ctrl/⌘ + ＋／－（或 Ctrl＋鼠标滚轮）调整成喜欢的大小，Ctrl/⌘+0 恢复。在正文点右键的「文字の大きさ」（文字大小）可以切换是否随窗口变化。
- **和本软件一起启动 VOICEVOX 引擎**：不打开 VOICEVOX 的编辑器，打开本软件时会自动一起启动语音引擎（不会询问；不需要时可以在左下角「接続設定…」关掉。使用中如果停止了，会自动重新启动，朗读和保存会继续下去）。
- **有 GPU 就用 GPU**：电脑有 GPU、并且 VOICEVOX 是可以使用 GPU 的版本时，会用 GPU 启动，生成声音快很多（在 RTX 5060 的笔记本上约快 4 倍）。不顺利时会自动改回 CPU；可以在左下角「接続設定…」的「GPU があれば使う」关掉。
- **四种语言的使用说明**：点右上角的「使い方」，会用浏览器打开随软件附带的使用说明（日语・英语・繁体中文・简体中文），不需要联网。

## 使用前的三个步骤

1. **安装 VOICEVOX**：VOICEVOX 是另一款免费软件，负责生成声音，本软件没有附带。请从 [VOICEVOX 官方网站](https://voicevox.hiroshiba.jp/) 下载安装。之后只要打开本软件，语音引擎就会自动一起启动。汉字上方的读音也只有在连上 VOICEVOX 时才会显示（连接之前，正文正上方会显示「ふりがな（漢字の上の読み）は、VOICEVOX を起動すると出ます」（启动 VOICEVOX 后就会显示读音），点旁边的「画面なしで起動」就能直接启动）。安装好之后，也可以用本软件左下角的「VOICEVOX起動」（打开 VOICEVOX）或「画面なしで起動」（不打开 VOICEVOX 的窗口，只启动语音引擎）来启动。打开本软件时，如果 VOICEVOX 没有在运行，会自动只启动语音引擎，不会询问；不需要时可以在左下角「接続設定…」里的「アプリと一緒に VOICEVOX を起動」关掉。
2. **安装本软件（推荐用一行命令）**
   - **Windows**：右键点击「开始」→「终端」，粘贴下面这一行后按 Enter：
     ```powershell
     irm https://raw.githubusercontent.com/rakuyou211-blip/TextToVoicevox/main/install.ps1 | iex
     ```
   - **Mac**：打开「终端」，粘贴下面这一行后按 Return：
     ```bash
     curl -fsSL https://raw.githubusercontent.com/rakuyou211-blip/TextToVoicevox/main/install.sh | bash
     ```
   Windows 会安装内含 Python 的版本，电脑里不需要先装 Python（下载约 200MB）。Mac 如果没有 Python，会先询问是否安装。完成后桌面（Mac 是启动台）会出现 **TextToVoicevox**。有新版本时，本软件上方会出现「新しい版があります」（有新版本）；用 Windows 一行命令安装的人，点「更新する」（更新）就会换成新版本（每天只向 GitHub 问一次最新版本号，只发送软件名称和版本，可在左下「接続設定…」关闭）。
3. **开始使用**：在左栏「① 取り込む」添加文件（添加后会自动提取文字，也可以点「▶ テキスト抽出 実行」）→ 在「② 声」选择声音 → 点正文下方的「▶ 再生」收听，或者在「③ 保存」点「♪ 音声を生成」保存为音频文件。
   按钮的样子：**涂上主题颜色的按钮**是最重要的操作（「▶ テキスト抽出 実行」「♪ 音声を生成」「▶ 再生」；浅色和深色主题是橙色，ずんだ是绿色，くっきり是蓝色）；**有浅色底的按钮**是常用操作；**只有边框的按钮**是偶尔用的操作（保存为 .txt、复制、上一行／下一行等）；只有文字的是工具，其中**带齿轮图标**的会打开**设置**；红字的「本文を全消去」会清空正文。窗口较窄时，「ふりがな」复选框会移到正文下方。不知道怎么用时，点右上角的「使い方」，就会用浏览器打开使用说明（日语・英语・繁体中文・简体中文，按电脑的显示语言打开）。

也可以从 [Releases](https://github.com/rakuyou211-blip/TextToVoicevox/releases/latest) 下载 zip。详细步骤请看 [英文 README](README.en.md)。

> 实话实说：目前还不是一键安装的 `.exe`／`.app`。用 Windows 的一行命令安装时会连 Python 一起装好；其他方式需要 Python。第一次设置时会联网下载组件，之后就完全离线。
