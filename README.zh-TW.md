# TextToVoicevox 🍂

🌐 **[English](README.en.md)** ｜ **[日本語](README.md)** ｜ 繁體中文（本頁） ｜ **[简体中文](README.zh-CN.md)**

把 PDF、圖片、電子書、青空文庫的日文，交給 VOICEVOX 的聲音（ずんだもん等）唸給你聽的免費桌面軟體。全部在你自己的電腦裡完成，不會把檔案上傳到網路。

我是 rakuyou211，一個人做軟體的業餘開發者。一開始只是想讓電腦把書和長長的 PDF 唸給我聽，就這樣做到了現在。還有很多不夠完美的地方，下面會老實寫出來。

> **非官方工具**：本軟體不是 VOICEVOX 官方的軟體，而是個人製作的工具，與 VOICEVOX 的開發方及各角色的權利人沒有關係。VOICEVOX 本體需要另外安裝（本軟體沒有內附）。

> ⚠️ **先說清楚：軟體的畫面（按鈕和選單）目前只有日文。** 讀出來的內容也是日文。比較適合已經看得懂一些日文的人，例如正在學日文、想聽自然日文發音的人。

## 適合誰

- **正在學日文的人**：把日文文章（課本、小說、新聞截圖）變成自然的日文語音。本文的漢字上方會直接顯示 VOICEVOX 的讀音（假名），可以拿來確認漢字怎麼唸。
- **想用耳朵讀日本文學的人**：直接讀取 [青空文庫](https://www.aozora.gr.jp/)（著作權已過期的日本名著，免費公開）的文字，會自動去掉注音標記。
- **眼睛累、不想再盯著小字的人**：掃描的 PDF、拍下來的書頁，都能變成聲音。

## 可以做什麼

- **從畫面直接讀**：按「📷 スクリーンショット」（截圖），用滑鼠框住螢幕上的文字（電子書、PDF、網頁），馬上唸出來（Ctrl+R ／ ⌘R）。
- **支援多種檔案**：PDF（含掃描檔）、圖片（PNG・JPG 等）、`.txt`、`.docx`、`.epub`。
- **PDF 的頁眉和頁碼不唸**：PDF 的書每頁上方或下方的書名、章名（頁眉）和頁碼會去掉，不會每頁都唸一次（章節標題〔第一章 等〕的第一次會保留；去掉的行可以在「直した所」查看）。
- **離線 OCR**：圖片和掃描檔的文字都在電腦裡辨識，不上傳。Windows 使用 PP-OCRv6，**第一次設定時會自動安裝，不需要按任何按鈕**（下載約 122MB，安裝後約占 100MB）。遊戲畫面和照片上的文字、小字、日文夾雜英文的句子也讀得出來（我們測試的 258 張圖片中，讀對的字是 99.7%，Windows 內建的辨識是 89%）。沒裝成時會改用 Windows 內建的 Windows.Media.Ocr，並在 ① 的「設定 ▷」裡出現「読み取りを強くする」，可以從那裡重新安裝。Mac 使用 Apple Vision。直書文字會從右邊的行開始依序讀。
- **用 VOICEVOX 的聲音朗讀**：在自己的電腦上產生語音，可調整速度（速さ）、音高（高さ）等。
- **先改正容易唸錯的寫法**：數字、日期、符號等 VOICEVOX 容易唸錯的寫法，本軟體會在朗讀前先改成唸得對的寫法（不會改動本文。例如 `25℃`→25度、`10:30`→10時30分、`2026/11/7`→2026年11月7日、`10〜20人`→10から20人、`-5℃`→マイナス5度）。連續播放、試聽、存成音檔、假名讀音和給 VOICEVOX 的存檔（.txt・.vvproj）都適用。預設開啟，可在「読み方辞書...」視窗最上方的「数字・日付・記号の読み方を直す」關掉。
- **顯示聲音角色的臉**：在「② 声」選好的聲音旁邊，會顯示該角色的官方插圖（每種風格的表情不同）。點一下就能聽聲音範例。圖片來自你電腦上的 VOICEVOX，本軟體沒有內附。
- **一行換一個角色**：在行首寫 `@ずんだもん:` 之類的，就能換成別的聲音，做對話朗讀也很方便。
- **輸出音檔與字幕**：隨時可存成 WAV；另外也能輸出 MP3・M4A，以及有章節的有聲書 M4B（格式選「M4B(本)」。Windows 10 以上不需要另外安裝；Mac 只有 MP3 需要 ffmpeg）。還能同時輸出對齊的 `.srt` 字幕。預設把全部存成一個檔案（「③ 保存」的「まとめ方」是「全部を1つに」），也能改成每行一個檔案等；檔案會超過 300 個時，產生前會先詢問。
- **跟著正在唸的行**：連續播放時，正在唸的行會保持在本文欄上方約三分之一的位置，所以看得到下一句，折行的長句結尾也不會被遮住（自己捲動之後，會等 6 秒再跟上）。播放列右邊會顯示第幾行和「あと約◯分」（還剩大約幾分鐘）。
- **把本文放大（閱讀模式）**：按播放列右端的「◁ 広げる」（F11），左欄會收起來，本文佔滿整個視窗，文字也會配合視窗的寬度變大。按「▷ 戻す」，或在沒有播放時按 Esc 就能恢復。
- **段落和章節之間停久一點**：換段落的地方（空行之後，或行首用全形空格縮排）停句間的 2.5 倍，章節標題（第一章、プロローグ 等）之前停 5 倍（句間 0.4 秒時，分別是 1.0 秒和 2.0 秒）。播放、存成的音檔、字幕和 M4B 的章節時間都適用。可以用「③ 保存」的「段落・章は長め」切換（預設開啟）。行首用全形空格縮排的段落也認得出來，所以小說等即使開著「空行を削除」（刪除空行，預設開啟）也會在段落之間停頓。沒有縮排的文字要在段落之間停頓時，請在「① 取り込む」的「設定 ▷」取消勾選「空行を削除」。
- **讀音字典**：唸錯的詞登錄一次就會記住。
- **漢字上方顯示讀音（假名）**：本文的漢字上方會顯示 VOICEVOX 實際的唸法（預設開啟），聽之前就能發現唸錯的地方。和字典不同的讀音會用顏色標出（可能唸錯），點一下就會打開讀音字典，可以直接修正。只想看可能唸錯的地方時，請勾選「誤読候補だけ」。長篇的書也可以按「次の候補 ▷」（F8；回到上一個是 Shift+F8），依序跳到每個可能唸錯的地方。
- **本文文字大小配合視窗**：把視窗拉寬，本文（和假名）的文字會跟著變大，直到一行大約 36 個字；視窗窄的時候不會變小。可以用 Ctrl/⌘ + ＋／－（或 Ctrl＋滑鼠滾輪）調整成喜歡的大小，Ctrl/⌘+0 恢復。在本文按右鍵的「文字の大きさ」（文字大小）可以切換要不要配合視窗。
- **和本軟體一起啟動 VOICEVOX 引擎**：不開 VOICEVOX 的編輯器，開啟本軟體時會自動一起啟動語音引擎（不會詢問；不需要時可以在左下角「接続設定…」關掉。使用中如果停止了，會自動重新啟動，朗讀和存檔會繼續下去）。
- **有 GPU 就用 GPU**：電腦有 GPU、而且 VOICEVOX 是可使用 GPU 的版本時，會用 GPU 啟動，產生聲音快很多（在 RTX 5060 的筆電上約快 4 倍）。不順利時會自動改回 CPU；可在左下角「接続設定…」的「GPU があれば使う」關掉。
- **四種語言的使用說明**：按右上角的「使い方」，會用瀏覽器打開隨軟體附帶的使用說明（日文・英文・繁體中文・簡體中文），不需要連網。

## 使用前的三個步驟

1. **安裝 VOICEVOX**：VOICEVOX 是另一套免費軟體，負責產生聲音，本軟體沒有內附。請從 [VOICEVOX 官方網站](https://voicevox.hiroshiba.jp/) 下載安裝。之後只要開啟本軟體，語音引擎就會自動一起啟動。漢字上方的讀音也只有在連上 VOICEVOX 時才會顯示（連線之前，本文正上方會顯示「ふりがな（漢字の上の読み）は、VOICEVOX を起動すると出ます」（啟動 VOICEVOX 後就會顯示讀音），按旁邊的「画面なしで起動」就能直接啟動）。安裝好之後，也可以用本軟體左下角的「VOICEVOX起動」（開啟 VOICEVOX）或「画面なしで起動」（不開 VOICEVOX 的視窗，只啟動語音引擎）來啟動。開啟本軟體時，如果 VOICEVOX 沒有在執行，會自動只啟動語音引擎，不會詢問；不需要時可以在左下角「接続設定…」裡的「アプリと一緒に VOICEVOX を起動」關掉。
2. **安裝本軟體（建議用一行指令）**
   - **Windows**：在「開始」按右鍵 →「終端機」，貼上這一行後按 Enter：
     ```powershell
     irm https://raw.githubusercontent.com/rakuyou211-blip/TextToVoicevox/main/install.ps1 | iex
     ```
   - **Mac**：打開「終端機」，貼上這一行後按 Return：
     ```bash
     curl -fsSL https://raw.githubusercontent.com/rakuyou211-blip/TextToVoicevox/main/install.sh | bash
     ```
   Windows 會安裝內含 Python 的版本，電腦裡不需要先裝 Python（下載約 200MB）。Mac 沒有 Python 的話，會先詢問要不要安裝。完成後桌面（Mac 是 Launchpad）會出現 **TextToVoicevox**。有新版本時，本軟體上方會出現「新しい版があります」（有新版本）；用 Windows 一行指令安裝的人，按「更新する」（更新）就會換成新版本（每天只向 GitHub 問一次最新版本號，只送出軟體名稱和版本，可在左下「接続設定…」關掉）。
3. **開始使用**：在左欄「① 取り込む」加入檔案（加入後會自動取出文字，也可以按「▶ テキスト抽出 実行」）→ 在「② 声」選擇聲音 → 按本文下方的「▶ 再生」聆聽，或在「③ 保存」按「♪ 音声を生成」存成音檔。
   按鈕的樣子：**塗上主題顏色的按鈕**是最重要的操作（「▶ テキスト抽出 実行」「♪ 音声を生成」「▶ 再生」；淺色和深色主題是橘色，ずんだ是綠色，くっきり是藍色）；**有淡色底的按鈕**是常用的操作；**只有外框的按鈕**是偶爾用的操作（存成 .txt、複製、上一行／下一行等）；只有文字的是工具，其中**帶齒輪圖示**的會打開**設定**；紅字的「本文を全消去」會清除本文。視窗較窄時，「ふりがな」勾選框會移到本文下方。不知道怎麼用時，按右上角的「使い方」，就會用瀏覽器打開使用說明（日文・英文・繁體中文・簡體中文，依電腦的顯示語言開啟）。

也可以從 [Releases](https://github.com/rakuyou211-blip/TextToVoicevox/releases/latest) 下載 zip。詳細步驟請看 [英文 README](README.en.md)。

> 老實說：目前不是一鍵安裝的 `.exe`／`.app`。用 Windows 的一行指令安裝時會連 Python 一起裝好；其他方式需要 Python。第一次設定時會連網下載元件，之後就完全離線。

## 關於 VOICEVOX 的聲音（請一定要看）

聲音來自 **VOICEVOX** 以及各角色的聲音資料庫，有各自的使用條款。**公開使用做出來的聲音時，大多數角色都需要標示來源**（例如「VOICEVOX:ずんだもん」）。各角色的規定不同，請以官方條款為準。本軟體的作者沒有這些聲音的權利。

朗讀有著作權的書並公開音檔，可能會侵害著作權。請用在自己聽的範圍內，或使用青空文庫這類著作權已過期的作品。
