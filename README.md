**本や書類を「ずんだもん」たちに読み上げてもらう、無料のデスクトップアプリです。**

PDF・画像・txt・docx・epub から文字を取り出して、あなたのパソコンの中の VOICEVOX で朗読・音声化します。文字を目で追うのがつらいときに、耳で聴くという選択肢を。

これは「落葉いの道具箱 🍂」のひとつです。ひとりで作っているので、まだ粗いところもあります。それでも、小さな困りごとに手作りの道具を、というつもりで置いています。

> **非公式のツールです。** VOICEVOX 公式のソフトではなく、個人が作ったものです。VOICEVOX の開発元や、各キャラクターの権利者とは関係ありません。VOICEVOX 本体は別に入れて使います（このアプリには入っていません）。

## ⬇ ダウンロード（最新版）

### Windows の人（おすすめ・「PCが保護されました」が出ません）

スタートボタンを右クリック →「**ターミナル**」を開いて、次の1行を貼り付けて Enter。

```powershell
irm https://raw.githubusercontent.com/rakuyou211-blip/TextToVoicevox/main/install.ps1 | iex
```

**Python 入りの版**を入れるので、**Python を入れる必要はありません**（ダウンロード約200MB）。アプリを入れて、**デスクトップに「TextToVoicevox」のアイコン**を作ります。以後はアイコンから起動するだけ。更新も同じ1行です（くわしくは下の「③ このアプリを入れる」）。

### Mac の人（おすすめ・「開けません」が出ません）

「ターミナル」（Launchpad で「ターミナル」と検索）を開いて、次の1行を貼り付けて return。

```bash
curl -fsSL https://raw.githubusercontent.com/rakuyou211-blip/TextToVoicevox/main/install.sh | bash
```

Python が無ければ入れるかを聞き（パスワード不要）、アプリを入れて、**Launchpad に「TextToVoicevox」**を作ります。以後は Launchpad か Spotlight（⌘+スペース）から起動するだけ。更新も同じ1行です（くわしくは下の「③ このアプリを入れる」）。

**コード署名について**：Windows 用の起動用 `TextToVoicevox.exe` は、[SignPath Foundation](https://signpath.org/) の証明書で署名します（無料のコード署名は [SignPath.io](https://about.signpath.io/) の提供）。方針は [docs/CODE_SIGNING.md](docs/CODE_SIGNING.md) に書いています。いまは申し込み中で、通るまでは .exe を入れずに配ります（`起動.pyw` が同じ役目をしています）。

### zip で入れたい人

- **⬇ [Windows 用をダウンロード](https://github.com/rakuyou211-blip/TextToVoicevox/releases/latest/download/TextToVoicevox_Windows.zip)**（`TextToVoicevox_Windows.zip`）

- **Mac の人は、zip ではなく、上の「Mac の人」のターミナルの1行を使ってください**（警告が出ません）。
  zip が欲しい人は → [Mac 用 zip](https://github.com/rakuyou211-blip/TextToVoicevox/releases/latest/download/TextToVoicevox_Mac.zip)（`TextToVoicevox_Mac.zip`）。ただし、ブラウザで落とした zip の中身を**ダブルクリックすると、Mac が必ず「開いていません」と止めます**（Apple の有料の審査を受けていないアプリには、どれも出ます）。zip で入れるときは、下の「zip で入れる」の Mac の手順どおり、ダブルクリックではなくターミナルから始めてください。そうすれば出ません

## こんなときに

- 分厚いPDFの資料や本を、**家事をしながら耳で聴きたい**
- 目が疲れていて、これ以上**画面の細かい文字を追いたくない**
- **ディスレクシア**などで、文字を読むより聴くほうが頭に入りやすい
- スキャンした書類・写真に撮った紙の文字を、**音声にして確認したい**
- 小説を**ずんだもんの声**で朗読させて、寝る前に流したい
- 字幕（.srt）付きの音声がほしい
- **ずんだもん達の掛け合い動画**を作りたい（行ごとに声を分けて、音声も字幕も一括で書き出し）

「読む」がしんどいときに、「聴く」に切り替えるための道具です。

## できること

- **スクリーンショットで読む**：「📷 スクリーンショット」を押して、電子書籍・PDF・Webページなど、画面の読みたい所を**ドラッグで囲むだけで、すぐ読み上げ**（Ctrl/⌘+R）。読んだ文字は本文にたまっていきます。ページをめくったら **↻ 同じ範囲を読む**（一度囲むと出るボタン・Ctrl/⌘+Shift+R）で囲み直さずに次のページへ。**「めくったら自動で読む」**をオンにすれば、ページをめくるだけで読み進められます（Macは初回だけ「画面収録」の許可が必要）
- **文字の取り出し**：PDF・画像（PNG/JPEG等）・txt・docx・epub に対応
- **オフラインOCR**：画像やスキャンPDFの文字を、PCの中だけで読み取り（ネットに送りません）
  Windows は **PP-OCRv6**（RapidOCR 経由・どちらも Apache-2.0）で読みます。**最初のセットアップで自動で入るので、押すものはありません**（約122MBのダウンロードで、アプリが約100MB大きくなります）。ゲームや写真の上の文字、小さな文字、英語まじりの文も読めます（試した258枚の画像で、正しく読めた文字は、Windows の標準の読み取りの 89% に対して 99.7%）。部品が入らなかったPCや、`ocr_engine` フォルダを消したPCでは、Windows の標準の読み取り（Windows.Media.Ocr）で読みます。そのときは ① の「設定 ▷」に **「読み取りを強くする」** が出るので、そこから入れ直せます。Mac は Apple Vision で読みます
- **縦書きも読めます**：列を右から順に読みます（電子書籍の縦書きのスクリーンショットなど）
- **VOICEVOXで音声化**：声・速さ・高さ・抑揚・音量を調整して WAV / M4A / MP3 で保存。最初は全部を1つのファイルにまとめます（③ の「まとめ方」で「1行=1ファイル」「行数ごと」「段落ごと」にもできます。ファイルが300個を超えるときは、作る前に聞きます）
  （WAVはいつでも保存できます。M4A・MP3・M4B も、Windows 10 以降なら何も入れずに作れます（Windows に入っている変換を使います。**ffmpeg** があれば、そちらを使います）。Mac は M4A・M4B をOS標準の afconvert で作れるので、ffmpeg が要るのは MP3 のときだけです）
- **オーディオブック出力（M4B）**：③ の音声形式で「M4B(本)」を選ぶと、全文を1ファイルにまとめ、章見出し（第◯章など）から自動でチャプターを埋め込み。Apple Books等で「本」として頭出しできます
- **声サンプル試聴**：声を選ぶとき「♪ 声を聴く」でキャラの公式サンプルを再生
- **声のキャラの顔**：② で選んだ声のキャラの顔（VOICEVOX が持っている公式のイラスト。スタイルごとに表情が違います）を、声の選択の横に出します。押すと、その声のサンプルを聴けます（画像はアプリに入っておらず、あなたの VOICEVOX から表示するだけです）
- **読み確認**：試聴すると「どう読んだか」をカナで表示。誤読は読み方辞書ですぐ直せます
- **ふりがな**：本文の漢字の上に **VOICEVOX が実際に読む読み** が出ます（最初からオン。VOICEVOX につながっているときに出ます。本文の右上の「ふりがな」で切り替え。窓の幅が狭いときは本文の下）。聴く前に誤読を見つけられます（辞書と違う読みは色つきのカタカナ。押すと、その語の読みを辞書で直せます）。長い本でも、本文の右上の **「次の候補 ▷」**（F8。前へは Shift+F8）で、誤読候補を順に見て回れます。書き方を確かめる辞書（Janome）は初回セットアップで入ります（ダウンロード約20MB。Windows はセットアップで自動的に圧縮するので、アプリは約50MB大きくなるだけです。Mac は約250MB）
- **本文の文字は、窓に合わせた大きさに**：窓を広げると、1行がだいたい36字になるまで本文の文字（とふりがな）が大きくなります（狭い窓では小さくしません）。好みの大きさは Ctrl/⌘ + ＋／－（Ctrl+ホイールでも）、元に戻すのは Ctrl/⌘+0。本文の右クリックの「文字の大きさ」で、窓に合わせるかどうかも切り替えられます
- **＃メモ行**：行頭に `#` を付けた行は読み上げから除外（台本メモに）
- **連続再生＋しおり＋一時停止**：長い本も途中から聴き直せます（スペースキーで一時停止/再開）
- **読んでいる行を追いかける**：連続再生では、読んでいる行を本文欄の上から3分の1あたりに保つので、次の文も見えて、折り返す長い文の終わりも隠れません（自分でスクロールした直後は6秒待ちます）。再生バーの右に、何行目かと「あと約◯分」が出ます
- **本文を広げる（読書モード）**：再生バーの右端の「◁ 広げる」（F11）で左の列を畳み、本文を窓いっぱいに広げます。文字も窓の幅に合わせて大きくなります。「▷ 戻す」か、何も鳴っていないときの Esc で戻ります
- **段落・章の切れ目は長めに**：段落が変わる所（空行のあと・行頭の字下げ）は文の間の2.5倍、章の見出し（第一章・プロローグ など）の前は5倍の間を空けます（文の間が0.4秒なら1.0秒・2.0秒）。連続再生にも、保存する音声・字幕・M4Bの章にも効きます（③ の「段落・章は長め」で切り替え。最初からオン）。行頭の字下げ（全角スペース）でも段落を見分けるので、小説などは「空行を削除」（最初からオン）のままでも段落の間が空きます。字下げの無い文章で段落の間を空けるときは、① の「設定 ▷」の「空行を削除」を外してください
- **生成のキャンセル**：長い本の音声生成を途中で止められます（Esc）
- **行ごとに声を変える**：行の頭に `@ずんだもん:` と書くと、その行だけ声が変わります。セリフ（「」で始まる行）だけを別の声にもできます（② の「お気に入り・セリフ ▷」）。ナレーターとセリフで声を分けるような使い方も
- **字幕（.srt）出力**：結合音声に合わせた字幕を書き出し
- **読み方辞書**：固有名詞などの読み間違いを登録して直せます（上書き・編集・登録した読みの試聴も）
- **一度作った声は、しまっておく（行ごと）**：誤読を1行直して再生成しても、他の行は作り直さず即完了。連続再生で聴いた本の音声化もほぼ一瞬（しまってある量は ③ の「声の保管…」で確かめたり消したりできます）
- **10時間級の長編にも対応**：音声生成は逐次書き出しでメモリほぼ一定。キャンセルしても「ここまでを保存」できます
- **PDFのページ範囲指定**：`5-320` のように指定して表紙・目次・索引を読み飛ばし
- **PDF の柱とページ番号は読まない**：ページごとの上や下に出る本や章の名前（柱）とページ番号を外します。柱が「第一章　…」でも、毎ページの前に章の間が入ったり、M4B の章がページごとにできたりしません（章の見出し〔第一章 など〕は、最初の1回を残します。外した行は「直した所」で見られます。① の「設定」の「PDF のページの見出しと番号を読まない」で切れます）
- **掛け合い素材の整理支援**：分割出力にセリフ一覧CSV（ファイル名・話者・テキスト・長さ）を自動保存。複数の声ならファイル名にも声の名前が入ります
- **右クリックメニュー**：本文の右クリックから「この行を試聴」「選択語を辞書登録」「この行を別の声で読む」「＃メモ行にする」へ一直線
- **完了ダイアログから保存先を開く・クレジットをコピー**：公開時に必要な `VOICEVOX:キャラクター名` の表記をワンクリックでコピーできます
- **本文の自動保存**：60秒ごとに自動保存。クラッシュしても次回起動時に復元されます
- **折り返しを賢く連結**：画像OCRでは行の座標を使って、折り返しで割れた1文を確実につなぎ直します（見出し・箇条書き・別段落は尊重、誤連結なし）
- **青空文庫のルビ除去・Web小説の「漢字(かんじ)」型ルビ除去**
- **画面キャプチャのノイズ除去**：ニュースやSNS埋め込みのスクショから、時刻・局ロゴ・SNSハンドル・矢印などの“映像内オーバーレイ文字”を除いて本文だけ読み上げ（既定ON・保守的判定）
- **映像内ラベルの除去**：ニュース画像OCRに残る局ロゴ・番組名・日時・カテゴリ表示などの短い日本語ラベル（例「MBSニュース」「国内」）を、行の座標・文字サイズから本文でないと判定して除きます（Windows/Mac両対応・上のノイズ除去と共通ON/OFF・本文は必ず残す保守的判定）
- **読み取りの間違いの自動補正**（① の「読み取りの間違いを直す」）：OCRが取り違えやすい同形文字（`サ一ビス`→`サービス`・`卜ヨタ`→`トヨタ`・`2O26`→`2026` など）を前後の文脈で確定できるときだけ直します（既定ON・OCR結果のみ対象。テキストファイルには触れません）
- **数字・日付・記号の読み方を直す**：VOICEVOX が読み間違える書き方を、読み上げる前に直します（本文の字は変えません。最初からオン）。例: `25℃`→25度、`10:30`→10時30分、`2026/11/7`→2026年11月7日、`10〜20人`→10から20人、`-5℃`→マイナス5度、`100m`→100メートル、`①`→1、`㈱`→株式会社、`草www`→草。連続再生・試聴・音声の保存・ふりがな・VOICEVOX 用の保存（.txt・.vvproj）に効きます。もともと正しく読める物（iPhone・50%・5km など）や、分数か日付か分からない `1/3` には触りません。切るときは「読み方辞書...」の窓のいちばん上で。取り出した本文の字そのものをそろえたいときは、① の「詳細設定」の「字の形をそろえる」を使います
- **ダークモード（Windows はタイトルバーも暗く）・文字サイズ変更・本文検索・主要操作のショートカット**（スクリーンショット=Ctrl/⌘+R・抽出=Ctrl/⌘+Return・生成=Ctrl/⌘+G・試聴=Ctrl/⌘+P・停止=Esc など）
- **アプリと一緒に VOICEVOX を起動**：アプリを開くと、VOICEVOX の読み上げの部分も自動で立ち上がります（VOICEVOX のエディタ画面は開きません。何も聞きません。いらなければ左下の「接続設定…」で切れます。使っている途中で止まっても、自動で起動し直し、読み上げや音声の保存はそのまま続きます）。GPU のあるパソコンで、VOICEVOX が GPU を使える版なら、GPU で起動して音声を速く作ります（RTX 5060 のノートパソコンで約4倍。30万字の本で 約86分 → 約22分）。うまく動かないときは、自動で CPU に戻します。切るときは「接続設定…」の「GPU があれば使う」で
- **使い方の案内**：右上の「使い方」で、使い方の案内をブラウザで開けます（日本語・English・繁體中文・简体中文。パソコンの表示言語に合わせて開きます。ネットにはつながりません）
- **CLI（コマンド）モード**：GUIなしで一括変換（自動化・上級者向け）

## 使うまでの順番（ここ大事）

このアプリは単体では音を出せません。**先に VOICEVOX を用意する**必要があります。順番を守ってください。

### ① まず VOICEVOX を入れて、起動しておく

音声を作っているのは VOICEVOX 本体です。このアプリには**同梱していません**。

1. [VOICEVOX公式サイト](https://voicevox.hiroshiba.jp/) から VOICEVOX をダウンロードしてインストール
2. あとは何もしなくて大丈夫です。このアプリを開くと、VOICEVOX の読み上げの部分も**自動で立ち上がります**

> VOICEVOXが動いていないと、このアプリの左下に「VOICEVOX: つながっていません」と出ます。本文の漢字の上の**ふりがなも、VOICEVOX につながっているときにだけ出ます**（つながっていないときは、本文のすぐ上に「ふりがな（漢字の上の読み）は、VOICEVOX を起動すると出ます」と出ます。となりの「画面なしで起動」で、そのまま起動できます）。

自分で起動したいときは、画面の左下の「接続」にある **「VOICEVOX起動」**（エディタ画面つき。あとで手直ししたいとき）と **「画面なしで起動」**（VOICEVOX の画面を開かずに、読み上げの部分だけ。起動が軽く、このアプリを閉じると一緒に終わります）を押します。準備ができ次第、そのままつなぎにいきます。

このアプリを開いたときに VOICEVOX が動いていなければ、VOICEVOX の読み上げの部分だけを**何も聞かずに一緒に起動します**（VOICEVOX のエディタ画面は開きません。VOICEVOX をもう開いているときは、それにつなぎます。このアプリを閉じると、一緒に終わります）。いらないときは、左下の **「接続設定…」** の中の **「アプリと一緒に VOICEVOX を起動」** を切ってください。

### ② Python を入れる

zip の配布物は Python のスクリプトです。パソコンに Python が必要です（Windows の1行導入なら要りません。Python 入りの版を入れます）。

- [python.org](https://www.python.org/downloads/) から **Python 3.9 以降**を入れるのがおすすめです
- Windowsのインストーラでは、最初の画面の **「Add Python to PATH」にチェック**を入れてください
- （画面表示に tkinter を使います。python.org版のWindows/Mac標準インストーラなら最初から入っています）

### ③ このアプリを入れる

#### Windows：1行でかんたん導入（おすすめ・警告が出ません）

1. スタートボタンを右クリック →「**ターミナル**」（または「Windows PowerShell」）を開く
2. 次の1行をコピーして、貼り付けて Enter

```powershell
irm https://raw.githubusercontent.com/rakuyou211-blip/TextToVoicevox/main/install.ps1 | iex
```

これだけで、**Python 入りの版**（アプリ・Python・部品・画像の文字を読む部品が全部入った約200MBの zip）を取ってきて `%LOCALAPPDATA%\TextToVoicevox` に置き、**デスクトップとスタートメニューに「TextToVoicevox」のアイコン**を作って起動します。**このパソコンに Python は要りません**。以後はアイコンから起動するだけです。

- **「PCが保護されました」が出ません**。あの警告は「ブラウザで落としたファイル」に付く印が原因で、この方法はPowerShell自身が取ってくるので印が付かないからです
- 新しい版にするときも**同じ1行**を貼るだけ（設定・辞書・自動保存・立ち絵はそのまま残ります）
- 新しい版が出ると、アプリの上の帯に「**新しい版があります**」と出ます。押して「**更新する**」を選べば、1行を貼らなくても入れ替わります（開いたときに1日1回、GitHub に最新の版だけを聞きます。送るのはアプリの名前と版だけで、左下の「接続設定…」の「新しい版が出たら知らせる」で切れます）。zip で入れた人は、押すとダウンロードのページを開けます
- Python 入りの版は、ブラウザで落とす形では配っていません。ブラウザで落とした zip を展開すると、Windows のウイルス対策（Defender）が Python の部品を約4分つかんで離さず、そのあいだアプリを開けないためです（この1行なら数秒で広がります）
- 中身は [`install.ps1`](install.ps1) で全部読めます。管理者権限は使いません
- やめるときは `%LOCALAPPDATA%\TextToVoicevox` フォルダと、2つのアイコンを消すだけです

#### Mac：1行でかんたん導入（おすすめ・警告が出ません）

1. Launchpad で「**ターミナル**」と検索して開く
2. 次の1行をコピーして、貼り付けて return

```bash
curl -fsSL https://raw.githubusercontent.com/rakuyou211-blip/TextToVoicevox/main/install.sh | bash
```

これだけで、**使える Python が無ければ入れるかを聞いて**（このアプリ専用の Python 3.12 を `~/.local/python3.12` に入れます。パスワード不要）、アプリを `~/Library/Application Support/TextToVoicevox` に置き、部品を入れ、**`~/Applications` に「TextToVoicevox」アプリ**を作って起動します。Launchpad と Spotlight から開けます。

- **「開けません」が出ません**。あの警告は「ブラウザで落としたファイル」に付く検疫フラグが原因で、この方法は curl が取ってくるので印が付かないからです
- 新しい版にするときも**同じ1行**を貼るだけ（設定・辞書・自動保存・立ち絵はそのまま残ります）
- 「スクリーンショット」を初めて使うときだけ、Mac が「画面収録」の許可を聞いてきます（システム設定で「TextToVoicevox」をオンに）
- 中身は [`install.sh`](install.sh) で全部読めます。管理者権限は使いません
- やめるときは `~/Library/Application Support/TextToVoicevox` と `~/Applications/TextToVoicevox.app`（ここで Python を入れた場合は `~/.local/python3.12` も）をゴミ箱へ

#### zip で入れる（従来の方法）

1. 上の「⬇ ダウンロード」から、自分の OS 用の zip（`TextToVoicevox_Windows.zip` / `TextToVoicevox_Mac.zip`）を落として、**解凍**する（Windows は右クリック→「すべて展開」、Mac はダブルクリック。OS標準の解凍がおすすめです）
2. **Windows** → **`起動.pyw`** をダブルクリック。初回は黒い窓でセットアップが進み、終わるとそのままアプリが開きます。次からは、アプリの絵の「TextToVoicevox」から開きます（`起動.pyw` は `app` フォルダにしまわれます）
3. **Mac** → **ダブルクリックはしないで**、ターミナルを開いて `bash ` と打ち（最後に半角スペース）、フォルダの中の **`setup_mac.sh`** をターミナルへドラッグして return。これで警告を出さずに、準備から起動まで進みます（2回目からは `起動.command` のダブルクリックで開けます）

どちらも**これだけ**です。初回は自動でセットアップが走ります（venvを作って部品を入れるので、初回だけネットが要ります・数分）。

ほかのファイルは、ふだん触らなくて大丈夫：

- `はじめにお読みください.txt` … この手順と「開けないとき」の最短手順をまとめた道しるべ
- `How to use (日本語).html` など4つ … 使い方の案内（日本語・English・繁體中文・简体中文）。アプリの右上の「使い方」で開くものと同じで、ダブルクリックでも読めます
- `setup.command` … 部品を入れ直すためのもの（Mac。起動側が必要なときに自動で呼びます）。Windows は `app` フォルダの中の `venv` を消してから `起動.pyw` を開けば入れ直します
- `setup_mac.sh` … Mac で Gatekeeper に止められたときの確実な入口（下の「Macで警告が出たとき」参照）
- `デバッグ起動.pyw` / `デバッグ起動.command` …（Windows の zip では `app` フォルダの中）うまく動かないときに使うと、黒い画面にエラーの内容が出ます（**まだ一度も起動できていない状態からでも調べられます**）
- `winlaunch.py` / `winsetup.py` … Windows の `.pyw` が使う中身（ダウンロードの印を外す・初回セットアップ・起動）。直接は触りません

うまくいかなかったときは、フォルダ（Windows の zip では `app` フォルダ）に記録が残ります。**`起動エラー.log`** は「ダブルクリックしても窓が開かない」ほうの記録（起動そのものに失敗したときだけ・毎回上書き）、**`エラー.log`** は開いたあとで失敗したときの記録（抽出・音声化・再生など。「詳細を表示」と同じ内容を書き足していき、大きくなりすぎたら古いぶんから捨てます）。不具合を知らせてもらうときは、この中身を添えてもらえると助かります。

あとは、開いた画面にファイルをドラッグ＆ドロップ → 文字を取り出す → 必要なら直す → 音声を作る、の流れです。画面は2列で、左の列を上から「① 取り込む」「② 声」「③ 保存」と使い、右の本文のすぐ下の「▶ 再生」で聴きます。ボタンは、**テーマの色で塗ったボタン**が大事な操作（「▶ テキスト抽出 実行」「♪ 音声を生成」「▶ 再生」。ライト・ダークはオレンジ、ずんだは緑、くっきりは青）、**面のあるボタン**がよく使う操作、**枠だけのボタン**がときどき使う操作（.txt 保存・コピー・前の行／次の行など）です。面のない文字は道具で、**歯車の印**が付いたものは**設定**を開きます。赤い文字の「本文を全消去」は本文を消すボタンです。困ったときは、右上の **「使い方」** で使い方の案内をブラウザで開けます（日本語・English・繁體中文・简体中文。パソコンの表示言語に合わせて開きます）。

このアプリは、**個人（落葉い）が作っていて、有料の署名（コード署名）をしていません**。そのため、初めて動かすときに Windows の SmartScreen や Mac の Gatekeeper、ウイルス対策ソフトが「知らないやつだぞ」と警告を出すことがあります。

**署名について**：Windows 用の起動用 `TextToVoicevox.exe` は、オープンソース向けの無料のコード署名（SignPath Foundation）で署名する準備をしています。方針は [docs/CODE_SIGNING.md](docs/CODE_SIGNING.md) に書いています。

**警告を通すのは、出たとしても「最初の1回」だけです。** 起動のたびに、残りのファイルの警告ブロック（Windows の Mark of the Web / Mac の検疫フラグと実行権限）を自動で外すからです。手でコマンドを打つ必要はありません。

- **Windows**：`起動.pyw` が毎回、フォルダの中のダウンロードの印を外します（Python で印を消すだけなので一瞬です）。v1.23 までの `.bat` が残っていたら、それも片付けます
- **Mac**：`起動.command` が毎回、フォルダ直下の `.command` / `.sh` の検疫フラグと実行権限を直します

### Windows で警告が出たとき

- 上の「Windows：1行でかんたん導入」の1行なら、警告は出ません（入っている版もそのまま新しくなります）

**ウイルス対策ソフト**が止めることもあります。中身はただの起動・セットアップ用のスクリプトです。心配なら中身を読んでから許可してください。

### Mac で警告が出たとき

- **確実な道（どのmacOSでも・おすすめ）**

## コマンド（CLI）で使いたい人へ

GUIを使わず、一括で変換できます。`起動.pyw` / `起動.command` と**同じ venv の Python** で実行してください（Windows の zip では、`app` フォルダの中に cli.py と venv があります。1行導入で入れた人は `%LOCALAPPDATA%\TextToVoicevox\runtime\python.exe`）。

    # PDF/画像/テキスト → VOICEVOX向けの整形txtを作る（エンジン不要）
    python cli.py 本.pdf -o 出力フォルダ

    # 音声まで一括生成（VOICEVOX起動が必要）
    python cli.py 本.pdf -o 出力フォルダ --wav --speaker ずんだもん --combine --srt

`python cli.py -h` で全オプション（話速 `--speed`、字幕 `--srt`、ルビ除去 `--paren-ruby`、OCR解像度 `--dpi`、エンジンURL `--url` など）が見られます。
