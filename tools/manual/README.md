# 説明書の画像を撮り直す道具

説明書（`docs/manual/`）の画面の画像は、本物のアプリをここの道具で撮って作っています。
アプリの見た目を変えたら、撮り直して説明書と合わせます（Windows 専用）。

```
venv\Scripts\python.exe tools\manual\shoot.py --settings <声などを借りる settings.json>
```

- 動かす Python は、アプリの部品が入ったもの（アプリの venv など）。VOICEVOX が使える状態で動かします。
- 撮影は**見えないデスクトップ**の中で進むので、撮っているあいだも画面に窓は出ず、マウスやキーボードも奪いません（1〜2分）。
- 使っている人の設定・本文の自動保存・声の保管には書き込みません（`--settings` の物は写しを読むだけ）。
- 終わると `docs/manual/img/*.jpg` と、配る説明書（`tools/make_manual.py` が作る物）が書き換わります。差分を目で確かめてから commit してください。

| ファイル | すること |
| --- | --- |
| `shoot.py` | 下の3つを順に動かす |
| `capture.py` | アプリを開いて、いろいろな状態の画面（`SHOTS`）と、各部分の位置（`boxes.json`）を撮る |
| `make_images.py` | 撮った画面を切り抜いて縮め、JPEG にする。「画面の見かた」の A〜I の図も描く |
| `hidden_desktop.py` | コマンドを見えないデスクトップで動かす |
| `pwcap.py` | 画面に出ていない窓を撮る（PrintWindow） |

切り抜く範囲（`make_images.py` の `JOBS`）は、拡大率 250% の画面で決めてあり、ほかの拡大率では
その比で伸び縮みさせます。アプリの並びが変わってずれたときは `JOBS` を直します。
説明書が使う画像がすべてここで作られることは、`tests/test_manual.py` が確かめます。
