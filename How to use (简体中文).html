TextToVoicevox ・ Windows 版

从安装到开口朗读

把 PDF、图片、文本文件里的文字提取出来，用ずんだもん等 VOICEVOX 的声音读出来的软件。全部在你自己的电脑上运行，文字不会传到网络上。这一页也可以从本软件右上角的 使い方（使用说明）打开。

软件界面只有日文。下面的按钮名称照软件里的日文写，并附上中文说明。

VOICEVOX→Python→本软件→ 添加文件→提取文字→选择声音→生成语音

准备（只有第一次）

请按这个顺序安装。VOICEVOX 和 Python 是另外的软件，没有包含在本软件里。

  1. 1

    安装 VOICEVOX

    负责生成声音的主程序。请从 VOICEVOX 官方网站 下载安装。

    • 装好之后就不需要再做什么。打开本软件时，语音引擎会自动一起启动（不会打开编辑器窗口，关闭本软件时也会一起结束）。
    • 也想用编辑器窗口时，可以用本软件的 VOICEVOX起動（启动 VOICEVOX）按钮打开。
    • 不想自动启动时，可以关掉左下角 接続設定…（连接设置）里的 アプリと一緒に VOICEVOX を起動（和本软件一起启动 VOICEVOX）。
    • 如果电脑有 GPU，并且 VOICEVOX 是可以使用 GPU 的版本，本软件会用 GPU 启动（生成声音会快很多；在测试的电脑上约快 4 倍）。要关掉时，取消同一处的 GPU があれば使う（有 GPU 就使用）。
  2. 2

    安装 Python

    从 python.org 下载 3.9 及以上版本的安装程序并运行。

    最容易卡住的地方

    在安装程序的第一个界面，一定要先勾选「Add python.exe to PATH」再继续。

  3. 3

    启动本软件

    在解压后的文件夹里，双击 起動.pyw。

    • 只有第一次会出现黑色窗口进行设置（需要联网，大约几分钟）。
    • 完成后会直接打开本软件，之后就能马上打开。
    • 打开一次之后，会出现带本软件图标的「TextToVoicevox」快捷方式，起動.pyw 会收进 app 文件夹。之后打开这个快捷方式就可以了。
    • 有新版本时，上方会出现「新しい版があります」，点一下会说明怎么更新。
    • zip 文件请务必先右键 →「全部解压缩」再使用。

    另一种安装方式：在终端里粘贴一行就好（不需要 Python，不会出现警告，桌面会出现图标）

    irm https://raw.githubusercontent.com/rakuyou211-blip/TextToVoicevox/main/install.ps1 | iex

使用方法（每次的流程）

添加文件、提取文字、生成语音。基本上就是这四步。

  1. 1

    左栏 ① 取り込む

    添加要读的内容

    把 PDF、图片（PNG／JPG 等）、txt、docx、epub 拖放到窗口上。

    • 想读屏幕上的文字时，点 スクリーンショット（截图，Ctrl+R）框住范围就好，框完会马上读出来。
  2. 2

    左栏 ① 取り込む → 右边的正文

    提取文字

    添加文件后会自动提取文字，显示在右边的正文里。想重新提取时，点 ▶ テキスト抽出 実行（Ctrl+Enter）。

    • PDF 可以用 5-320 这样的页码范围，跳过封面和目录（① 的 設定 ▷）。
    • PDF 书每页上方或下方的书名、章名（页眉）和页码不会读出来（章节标题〔第一章 等〕的第一次会保留）。去掉的行可以在 直した所（修正的地方）查看。
    • 扫描件和照片上的文字也能识别（竖排会从右边的列开始），游戏画面和照片上的文字、小字、日文夹杂英文的句子也读得出来。
  3. 3

    右边的正文／左栏 ② 声

    修改并选择声音

    正文可以直接修改。汉字上方的假名是 VOICEVOX 实际的读法，听之前就能发现读错的地方（点一下有颜色的假名，就能修正那个词的读音）。在 ② 选择角色和声音风格，再用 ▶ 試聴（Ctrl+P）试听确认。

    • 假名读音只有在 VOICEVOX 运行时才会显示。没有运行时，正文正上方会显示 「ふりがな（漢字の上の読み）は、VOICEVOX を起動すると出ます」（启动 VOICEVOX 后就会显示读音），点旁边的 画面なしで起動 就能直接启动。窗口较窄时，假名的复选框在正文下方。
    • 勾选 「誤読候補だけ」，就只显示有颜色的读音（可能读错的地方）。
    • 篇幅长的书，可以用正文右上角的 次の候補 ▷（下一个候选，F8；回到上一个是 Shift+F8），依次跳到每个有颜色的读音。还没查过读音的行，会一边问 VOICEVOX 一边找。
    • 把窗口拉宽，正文的文字就会变大（窗口窄的时候不会变小）。用 Ctrl+＋／－（或 Ctrl＋鼠标滚轮）调整成喜欢的大小，Ctrl+0 恢复。点右键的 「文字の大きさ」（文字大小）可以选择是否随窗口变化。
    • 在行首写 @ずんだもん:，就只有那一行换成别的角色（适合对话）。
    • 行首加上 # 的行不会读出来（可以当备注）。
    • 读错的词，也可以选中后右键，登记到读音词典来修正。
    • 日期、时间、符号（25℃、10:30、2026/11/7、10〜20人 等），本软件会在朗读前先改成 VOICEVOX 能读对的写法（正文不会改变）。要关掉时，请取消 読み方辞書...（读音词典）窗口最上方的 数字・日付・記号の読み方を直す。
  4. 4

    正文下方的播放栏／左栏 ③ 保存

    收听，或保存为音频文件

    • ▶ 再生（正文正下方）… 从光标所在的行读到最后。按 Space 暂停／继续。正在读的行会保持在正文栏上方约三分之一的位置，看得到下一句。播放栏右边会显示第几行和 あと約◯分（还剩大约几分钟）。
    • ◁ 広げる（放大正文，F11，在播放栏右端）… 收起左栏，让正文占满整个窗口，文字也会跟着变大。点 ▷ 戻す，或在没有播放时按 Esc 就能恢复。
    • ♪ 音声を生成（Ctrl+G）… 保存为在 ③ 选择的格式（WAV 等）的文件。默认把全部保存成一个文件（可以在 ③ 的 まとめ方（分割方式）更改；文件会超过 300 个时，生成前会先询问）。勾选 字幕(.srt)も保存 就会同时导出字幕。
    • 段落・章は長め（段落和章节之间停久一点；在 ③ 的 文の間 右边，默认开启）… 换段落的地方（空行之后、行首缩进）和章节标题（第一章 等）之前，会比句子之间停得更久（句间 0.4 秒时，分别是 1.0 秒和 2.0 秒）。播放和保存都适用。行首用全角空格缩进的段落，即使开着 空行を削除 也能认出来。
    • 想中途停止时按 Esc。也可以把已经生成的部分保存下来。

可以保存的格式

格式用途需要的东西
WAV最稳定，可以直接用于视频剪辑无
M4A / MP3在手机上听、想让文件更小无（只有 Mac 的 MP3 需要 ffmpeg）
M4B(本)带章节的有声书（遇到「第◯章」会自动分章）无
.srt与声音对齐的字幕无

遇到问题时

双击 起動.pyw 没有反应／打开了记事本

没有安装 Python，或者忘了勾选 PATH。请重做准备的第 2 步。已经安装了 Python 却打开记事本时，请右键 →「打开方式」→ 选择「Python」。

出现「Windows 已保护你的电脑」

点小字的「更多信息」，再点「仍要运行」。只是作者没有做代码签名，源代码全部公开。

出现 「VOICEVOX: つながっていません」（没有连上 VOICEVOX）

VOICEVOX 没有在运行。装好之后，通常打开本软件时就会自动启动。如果没有启动，请点本软件左下（接続）的 VOICEVOX起動 或 画面なしで起動。如果每次都这样，请确认左下角 接続設定… 里的 アプリと一緒に VOICEVOX を起動 已经打开。

没有显示假名读音

假名读音只有在连上 VOICEVOX 时才会显示（连接之前，正文正上方会这样提示，旁边还有 画面なしで起動 按钮）。打开 VOICEVOX，或者点本软件左下（接続）的 VOICEVOX起動 或 画面なしで起動，连上后就会自动显示。窗口较窄时，假名的复选框在正文下方。

不知道原因

用 デバッグ起動.pyw 启动的话，黑色窗口会显示错误内容。文件夹里的 起動エラー.log、エラー.log 也会留下记录（用 zip 安装的话，都在 app 文件夹里）。

公开你生成的音频时，请遵守 VOICEVOX 和各角色的使用条款，并加上「VOICEVOX:ずんだもん」这样的署名。完成界面上的按钮可以复制署名文字。
