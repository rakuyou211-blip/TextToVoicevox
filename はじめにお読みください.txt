テキスト抽出 → VOICEVOX の始め方

■ さいしょに：zip は必ず「すべて展開」してください
  zip を開いた中身のまま起動すると、失敗します。Windows がそのファイルだけを
  一時フォルダに取り出してしまい、ほかのファイルを見つけられないためです。
  展開してできたフォルダの中から起動してください。
  Windows = zip を右クリック →「すべて展開」 ／ Mac = zip をダブルクリック
  （OS標準の解凍がおすすめ。一部のツールは日本語ファイル名や実行権限をこわします）

■ 先に用意するもの（2つ）
  ・Python … このアプリは Python のスクリプト一式です（EXE ではありません）。
    https://www.python.org/downloads/ から 3.9 以降を入れてください。
    Windows のインストーラでは、最初の画面の「Add python.exe to PATH」に
    必ずチェックを入れてください（ここが一番のつまずきどころです）。
    （Mac で画面が真っ白になるときも、ここの Python を入れると直ります）
  ・VOICEVOX … 音声を作っているのは VOICEVOX 本体です。同梱していません。
    https://voicevox.hiroshiba.jp/ から入れて、読み上げるときは起動したままに
    してください。起動していないと「エンジンに接続できません」になります。
    （文字を取り出すだけなら、VOICEVOX が無くても使えます）

■ Windows の人
  ★ 警告を出さずに入れる方法（おすすめ）:
    スタートボタンを右クリック →「ターミナル」を開き、次の1行を貼り付けて Enter。
      irm https://raw.githubusercontent.com/rakuyou211-blip/TextToVoicevox/main/install.ps1 | iex
    Python が無ければ入れるかを聞き、アプリを入れて、デスクトップにアイコンを作ります。
    以後はデスクトップの「TextToVoicevox」から起動するだけ。更新も同じ1行です。

  zip から使う場合は、展開して「起動.pyw」をダブルクリックするだけです。
  （初回は黒い窓でセットアップが進み、終わるとそのままアプリが開きます。
    初回だけネット接続が必要・数分かかります。2回目からはすぐ開きます）

    v1.24.0 から、zip に .bat は1つも入っていません。Windows 11 の
    「スマート アプリ コントロール」は、ネットから落とした .bat を
    中身も見ずに止めてしまうので、止められない .pyw だけにしました。
    前の版のフォルダに上書きで展開しても、古い .bat は 起動.pyw が自動で片付けます。

  ◆ 起動.pyw をダブルクリックしても何も起きない／「このファイルを開く方法」と聞かれるとき
    Python がまだ入っていないか、.pyw がほかのソフト（エディタなど）に
    関連付けられています。上の「先に用意するもの」の Python を入れてください。
    入れるときに「Add python.exe to PATH」のチェックを忘れずに。
    Python は入っているのにメモ帳などが開くときは、起動.pyw を右クリック →
    「プログラムから開く」→「Python」を選んでください。
    （上の1行導入なら、この関連付けに関係なく使えます）

  ◆「WindowsによってPCが保護されました」と出たとき（「詳細情報」がある窓）
    小さな「詳細情報」をクリック → 「実行」ボタン。
    作者が有料のコード署名をしていないだけで、中身は全部公開しています。
    （起動.pyw が、フォルダ内のダウンロードの印を自動で外します）

■ Mac の人
  ★ 警告を出さずに入れる方法（おすすめ）:
    Launchpad で「ターミナル」を開き、次の1行を貼り付けて return。
      curl -fsSL https://raw.githubusercontent.com/rakuyou211-blip/TextToVoicevox/main/install.sh | bash
    Python が無ければ入れるかを聞き（パスワード不要）、アプリを入れて、
    Launchpad に「TextToVoicevox」を作ります。更新も同じ1行です。

  zip から使う場合は、ダブルクリックせずに、次の「いちばん確実な道」から始めてください。
  （ダブルクリックすると、Mac が「"起動.command"は開いていません」と止めます。
    出てしまったら「ゴミ箱に入れる」は押さずに「完了」を押して、次の道へ）
  2回目からは「起動.command」のダブルクリックで開けます。

  いちばん確実な道（警告が出ない・どの macOS でも）:
    1. ターミナルを開く（Launchpad で「ターミナル」と検索）
    2. bash と打って、半角スペースを1つ入れる
    3. このフォルダの setup_mac.sh をターミナルの画面へドラッグして return
    （ターミナル経由なら Gatekeeper に止められず、実行権限が失われていても
      動きます。検疫フラグを直してから、そのまま起動まで進みます）
  マウスだけでやりたい人は（macOS 15 Sequoia 以降の正規ルート）:
    1. 「開けません」のダイアログを「完了」で閉じる
    2. システム設定 → プライバシーとセキュリティ → 下へスクロール
    3. 「"起動.command"はブロックされました」の隣の「このまま開く」→「開く」
    （むかしの macOS 14 以前なら、右クリック→「開く」→「開く」でも通せます）
  ※最初の1回さえ通れば、起動.command が残りのファイルの検疫フラグと
    実行権限を自動で直します。以降はふつうのダブルクリックで使えます。
  コマンドが分かる人向けの1行（ターミナルに貼り付け。場所は読み替え）:
    bash ~/Downloads/TextToVoicevox/setup_mac.sh

■ うまく動かないとき
  ・「デバッグ起動.pyw」（Mac は「デバッグ起動.command」）で起動すると、
    黒い画面にエラーの内容が表示されます。まだ一度も起動できていない
    状態からでも、ここから開けます。
  ・エラーの記録は、このフォルダに残ります。
    起動そのものに失敗したとき（画面が出ない）→「起動エラー.log」
    アプリが開いたあと、途中で失敗したとき →「エラー.log」
  ・部品を入れ直したいときは、Windows はこのフォルダの「venv」フォルダを消してから
    起動.pyw を開きます（Mac は「setup.command」）。ふだんは触らなくて大丈夫です。
  ・「英語OCRを入れる.pyw」は、英文の多い画像を読みたい人だけが使うものです（任意・Windows専用）。
    先に「起動.pyw」で一度アプリを開いてから使ってください。
    入れるとアプリが約240MB大きくなります。Windowsの［設定］→［時刻と言語］→［言語と地域］で
    「英語（米国）」を追加する方法なら、これを入れなくても英語を読めます。

■ キャラの立ち絵（画面右のイラスト）について
  紹介画像に写っているキャラの立ち絵は、このアプリに同梱していません。
  （立ち絵はキャラごとに権利者が違うので、勝手に配らないためです）
  assets/立ち絵/ フォルダに「キャラ名.png」（例：ずんだもん.png）を置くと、
  その話者を選んだときに表示されます。入手先・置き方・クレジットの書き方は
  assets/立ち絵/README.md にまとめてあります。無くてもアプリは全部使えます。
